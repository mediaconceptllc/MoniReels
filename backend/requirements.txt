# ---------------------------------------------------------------------------
# Base image dependencies. Deliberately WITHOUT torch.
#
# A CPU-only torch build is ~800 MB installed. It would triple the image,
# slow every cold start, and — on a container that does not read its own
# cgroup CPU limit — is the single most likely cause of a throttled service.
# The transcription pipeline degrades cleanly without it (app/stt/pipeline.py
# falls back to ffmpeg silencedetect chunking), so the optional ML stack
# lives in requirements-ml.txt and is installed only on a worker that wants
# VAD-accurate timings or vocal separation.
# ---------------------------------------------------------------------------
